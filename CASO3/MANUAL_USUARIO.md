# Manual breve para empleados

1. Ingrese con su usuario corporativo en `/login/`.
2. Para registrar entrada, abra **Marcar asistencia** y presione **Registrar ahora**.
3. Para registrar salida, vuelva a presionar el mismo botón.
4. Para solicitar una licencia o permiso, seleccione **Solicitar permiso**, complete fechas y motivo, y guarde.
5. El estado pendiente puede cambiar a aprobado o rechazado por su jefe o por RRHH.
6. Cierre sesión al terminar para proteger su cuenta.
